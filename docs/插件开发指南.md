# PlugKit 插件开发指南

> PlugKit | 工具市场 — 为创作者准备的插件协议文档。

一个 PlugKit 插件 = **一个 CLI 可执行文件 + 一个 HTML 界面**。插件通过标准 stdout JSON 协议与主程序通信,支持任意语言(Python / Rust / Go / Node…)。

## 目录结构

```
plugin-repo/
├── manifest.json              # 运行时清单(主程序读取)
├── tool/
│   ├── plugkit-<id>           # CLI 可执行文件
│   └── index.html             # iframe UI(可省略,纯 CLI 也可)
└── README.md
```

## manifest.json

| 字段 | 说明 |
|------|------|
| `id` | 插件唯一标识(与仓库一致,如 `download`) |
| `name` / `description` | 市场展示用 |
| `version` | semver,如 `0.1.0` |
| `platforms` | 支持平台:`windows-x64` / `macos-arm64` / `macos-x64` / `linux-x64` |
| `dependencies` | 共享依赖:`{"yt-dlp": ">=2024.01.01", "ffmpeg": ">=6.0"}`(由主程序统一提供,插件**禁止自带**) |
| `bridgeVersion` | 桥接 SDK 版本约束,固定 `">=1.0.0"` |
| `entry` | `{ "type": "cli", "executable": "...", "toolDir": "tool" }` |
| `commands` | CLI 命令定义:`{ "命令名": { "stdinArgs": [...], "output": "json" 或 "progress+json" } }` |
| `ui` | `{ "type": "iframe", "html": "index.html" }`(可选) |

## CLI stdout 协议

stdout **每行一个 JSON 对象**,禁止多行合并。

### 进度消息(`progress+json` 模式)

```json
{"type":"progress","percent":45.5,"speed":"2.3MB/s","eta":"30s","message":"下载中..."}
```

`percent` 允许 `null`(无百分比的任务)。**必须 `flush=True`**,否则主程序读不到实时进度。

### 结果(任务结束最后一行)

```json
{"type":"result","success":true,"data":{...}}
```

### 错误

```json
{"type":"error","code":"PLUGIN_ERROR","message":"下载失败：服务器返回 404"}
```

## iframe UI

插件 UI 是一个 HTML 文件,主程序通过 `plugkit://plugin/{id}/tool/index.html` 加载,**自动注入 bridge SDK**(`window.MT` / `window.PlugKit`)。

```html
<script>
  const MT = window.MT || window.PlugKit;
  // 调用插件命令
  const r = await MT.invoke('download', { url: '...', quality: '1080p' });
  // 订阅进度
  MT.onProgress((evt) => { console.log(evt.data.percent); });
  // 插件配置(独立于主程序设置)
  await MT.config.set('default_quality', '720p');
  const q = await MT.config.get('default_quality');
  // 日志(写入主程序统一日志目录)
  MT.log.info('开始下载');
  // 任务中心(长时间任务注册)
  const { task_id } = await MT.task.submit('download', { url: '...' });
</script>
```

## 共享依赖注入

插件在 manifest 声明 `dependencies`,主程序运行时通过**环境变量**注入路径:

- `PLUGKIT_FFMPEG` → ffmpeg 可执行路径
- `PLUGKIT_YTDLP` → yt-dlp 可执行路径

插件 CLI 应优先使用环境变量,找不到时回退到系统 PATH。

## 发布流程

1. 编写插件(用模板仓库起步)
2. 本地验证:`python3 tool/plugkit-<id>.py --help`
3. 创建 GitHub 仓库 `plug-kit/plugkit-<id>`
4. 打 tag 触发 CI 构建各平台 zip
5. 上传 Release(命名 `plugkit-<id>-{platform}.zip`)
6. 在清单仓库 `plug-kit/plug-kit-plugins` 提交插件条目

## 安全边界

- 插件在受限子进程中运行,工作目录为 `~/.plugkit/tmp/{id}/`
- 主程序强制 SHA256 + Zip-Slip 校验,插件包无法越界写入
- 插件 UI 在 iframe sandbox 中,不能访问主程序之外的系统能力
- 插件应遵守 stdout 协议,进度消息及时 flush
